# War Groups: Зона

Браузерная двухмерная тактическая RTS о живой постапокалиптической Зоне: группировки воюют за территории, отряды выполняют приказы и договариваются между собой, а мир продолжает меняться без участия игрока.

🎮 **[Играть в текущую версию](https://war-groups-zone.dmytrolevada.chatgpt.site)**

> Это моя первая разработка. Проект пока находится на стадии ранней альфы: основные системы уже работают, но впереди ещё много интерфейсной работы, контента, баланса и полировки. Я буду рад любой помощи — программированию, тестированию, балансу, интерфейсу, картам, звуку и идеям по развитию симуляции.

## Главная идея

Играть можно в двух форматах:

- **Глава группировки** — управлять всеми отрядами, территориями, экономикой, исследованиями, войной и дипломатией.
- **Командир отдельного отряда** — начать тремя бедными новичками, искать хабар и артефакты, брать заказы, торговать, вступать в группировки, предавать, устраивать засады и постепенно создавать собственную историю.

Это не набор декоративных экранов. Новые механики должны изменять единое состояние мира, взаимодействовать с уже существующими системами, сохраняться и проходить проверочные сценарии.

## Что уже работает

- единая масштабируемая карта Зоны и 14 проработанных секторов;
- локальные точки: базы, лагеря, блокпосты, аномалии и переходы;
- свободное управление отдельными бойцами внутри локации;
- перемещение, захват и удержание территорий;
- тактические перестрелки, дистанция, линия огня, укрытия и боеприпасы;
- ранения, мораль, доверие, характеры и специализации бойцов;
- найм людей разного уровня и стоимости;
- экономика, трофеи, снаряжение, артефакты и контракты;
- обыск местности, разведка, отдых и поиск артефактов;
- разговоры, полевая торговля, новости, задания, угрозы, засады и предательство;
- уникальное поведение, иерархия и правила набора десяти группировок;
- автономные войны, рейды, патрули, караваны и дипломатия между ИИ-группировками;
- мутанты, динамические события, Выбросы и туман войны;
- локальные сохранения в браузере;
- интерфейс для компьютера и телефона;
- автоматические проверки игровых систем и длительных симуляций.

## Текущее состояние

Версия **0.1.0 — ранняя альфа**.

Игровое ядро уже позволяет проходить полноценные сценарии, но проект ещё не является завершённой игрой. Особенно нужны:

- улучшение понятности интерфейса;
- больше интерактивных объектов на локациях;
- дополнительные карты, события, задания и диалоги;
- баланс экономики, боёв и темпа захватов;
- визуальные и звуковые материалы;
- тестирование на разных компьютерах и телефонах;
- поиск ошибок в долгих игровых сессиях.

## Как помочь

Можно открыть **Issue** с ошибкой или предложением. Для изменения кода — создать отдельную ветку и Pull Request. Подробности находятся в [CONTRIBUTING.md](CONTRIBUTING.md).

Особенно полезно указывать:

1. За кого и в каком режиме вы играли.
2. Что именно сделали перед ошибкой.
3. Что ожидали увидеть.
4. Что произошло на самом деле.
5. Устройство, браузер и скриншот, если он есть.

## Запуск локально

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка проекта:

```bash
npm run lint
npm test
```

## Важное замечание

Это некоммерческий фанатский прототип, вдохновлённый атмосферой постапокалиптических игр о Зоне. Проект не связан с GSC Game World и не является официальной игрой S.T.A.L.K.E.R. Перед возможным публичным коммерческим выпуском названия, символику, музыку и графические материалы необходимо полностью проверить с точки зрения прав правообладателей.
